# DeepFlow RL 论文目录入口

本目录包含已投稿论文的源文件。唯一的论文事实来源是 `FGCS-main.tex`；同目录的
图表为该源文件引用的生成产物。

修订论文文字、公式、表格、论断或图表前，必须先阅读完整的跨项目 Agent 上下文：

`E:\workspace\python\DeepFlow-RL\AGENTS.md`

对应实验代码目录为：

`E:\workspace\python\DeepFlow-RL`

简而言之，本文提出面向弱网络端云协同 LLM 推理的 Token-ID 投机框架 DeepFlow RL。
论文性能结论来自统一解析式/离散事件仿真器中的比较实验，并非真实硬件部署基准。
代码中的仿真器、模型/设备配置、PPO 产物、实验脚本和作图脚本必须与
`FGCS-main.tex` 保持一致。

处理审稿意见时，应先给意见分类，再将受影响的论文论断追溯到代码假设与实验脚本，
重生成相应输出，并记录完整配置和来源。尤其需要谨慎处理两项已知语义问题：论文中
RTT 的表述与实现中单次传输链路延迟的约定，以及解析 Prompt 扫描超过草稿/目标模型
名义位置长度上限的问题。两者均不能只靠改写论文文字来解决。

论文的有效修改完成后，必须同步至代码仓库根目录下的 `paper/`，检查差异并使用中文
描述完成包含全部项目文件的本地提交。远程发布仅推送不含 `models/` 训练模型目录的
代码发布分支或副本；论文源文件、图表与对应的代码/配置更新应尽可能放入同一逻辑
提交，确保后续审稿修订可追溯。
